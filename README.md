
Smart Diabetes & Mental Health Management System

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen?style=for-the-badge&logo=render)](https://smart-diabetes-mental-health.onrender.com)

An intelligent, web-based platform designed to bridge physical and psychological health for individuals living with diabetes. By combining health tracking, machine learning models, and holistic wellness tools, this application helps users manage both blood glucose levels and associated mental health factors like diabetes distress and burnout.

## 🌟 Key Features

- **🩺 Predictive Health Analytics:** Input vital stats and biological markers to assess risk levels for diabetes and related health complications.
- **🧠 Mental Health & Wellness Tracking:** Interactive screeners and mood tracking tailored to measure stress, anxiety, and diabetes distress.
- **📊 Personalized Insights & Dashboards:** Visual representations of glucose trends, psychological state, and actionable recommendations.
- **💡 Lifestyle & Coping Strategies:** Guidance on dietary adjustments, exercise, mindfulness, and coping mechanisms for chronic disease management.
- **🌐 Responsive Web Design:** Optimized for seamless access on desktop, tablet, and mobile browsers.

## 💻 Getting Started Locally

Follow these steps to run the project locally on your machine.

### Prerequisites

* [Python 3.8+](https://www.python.org/downloads/?utm_source=gemini) 
* [Git](https://git-scm.com/?utm_source=gemini) 

### Installation & Setup

1. **Clone the repository:**
```bash
git clone [https://github.com/sahil-0923/smart-diabetes-mental-health.git](https://github.com/sahil-0923/smart-diabetes-mental-health.git)
cd smart-diabetes-mental-health

```


2. **Create and activate a virtual environment:**
```bash
# On macOS/Linux:
python3 -m venv venv
source venv/bin/venv/bin/activate

# On Windows:
python -m venv venv
venv\Scripts\activate

```


3. **Install the required dependencies:**
```bash
pip install -r requirements.txt

```


4. **Run the local development server:**
```bash
python app.py

```


5. **Access the application:**
Open your browser and navigate to `http://127.0.0.1:5000` (or the port specified in your console output).
